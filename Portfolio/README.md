# Ayush Jha – Personal Portfolio

A modern, responsive personal portfolio website built with plain HTML and CSS.

## Features
- Hero section with profile photo
- About Me with stats (Publication, Projects, KMs Run)
- 3 Project showcases with GitHub links
- Contact section with LinkedIn, GitHub and Gmail

## Projects Showcased
| Project | Description |
|---|---|
| [CipherVault AWS](https://github.com/AyushJha004/CipherVault-AWS) | Secure file encryption & storage on AWS Elastic Beanstalk |
| [ShopEasy – AI E-commerce](https://github.com/AyushJha004/ShopEasy-AI-Ecommerce) | Full-stack AI-powered e-commerce platform using Gemini API |
| [SEC Filing RAG Analyst](https://github.com/AyushJha004/sec-filing-rag-analyst) | AI financial research assistant for SEC EDGAR filings using RAG |

## Run Locally
```bash
cd Portfolio
python -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.
